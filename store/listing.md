# Chrome 网上应用店上架资料

名称和一句话简介取自上传包中的 manifest.json。主要语言选简体中文，可见性选公开（Public），分类优先选择 Workflow & Planning（工作流程与规划）。

## 详细介绍

你还记得收藏的网页是做什么的，却想不起标题？书签寻迹帮你从 Chrome 书签里找回那个页面。输入标题片段、网址或文件夹名称，就能在本地看到匹配结果，无需配置模型。

想按用途查找时，可以连接自己的 AI 模型，为选定文件夹生成页面摘要和检索词。试着输入「之前收藏的 PDF 表格提取工具」，用 AI 对话搜索找回相关书签。

- 按 Alt+Shift+B 打开书签搜索框，通过方向键选择结果，按回车打开。
- 新增、编辑或删除书签后，本地索引自动同步；配置模型后，新增和编辑的书签还可自动生成摘要。
- 在树状目录中选择建库范围、查看摘要、排除文件夹或清理索引。已有摘要可复用。
- 书签索引和备注保存在当前 Chrome 配置中。AI 功能需自行配置兼容的模型服务，其费用取决于提供方。对话搜索发送查询文字，建库发送标题、处理后的网址和可取得的网页摘录。填写的 API 密钥只用于向所配置的网关认证。

## 审核资料

单一用途为帮助用户搜索并找回自己的 Chrome 书签。基础搜索可直接测试：创建一个书签，打开扩展，用标题片段搜索，即可打开结果。AI 搜索和摘要需配置兼容的 Chat Completions 网关。

- bookmarks 权限用于读取书签树并监听新增、变更、移动和删除。
- storage 权限用于保存用户选择的模型设置、密钥、建库进度和目录范围。
- alarms 权限用于唤醒后台处理待建库书签。
- 可选 HTTP(S) 网站权限用于连接用户指定的网关以及读取用户书签指向的公开页面。网站和网关的域名由用户决定。
- 运行代码随扩展打包。模型响应按 JSON 数据解析。隐私披露涵盖书签网址、网页内容、用户查询以及发给所配置网关的认证密钥。
