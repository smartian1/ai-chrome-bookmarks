Model Gateway

Data & Privacy

Bookmark indexes, personal notes, and your API key are stored in this Chrome profile. Standard search runs locally. When calling a model, your API key is sent only as authentication to your configured gateway. AI Search sends your query text. Indexing sends bookmark titles, cleaned URLs, and available page excerpts. How the gateway routes or retains data depends on its provider. HTTPS is recommended for remote gateways.
