书签索引

同步会重新读取此 Chrome 配置的书签，将新增、改名、移动和删除反映到本地搜索，无需调用模型。

输入即可在本地搜索书签。配置模型后，新收藏的书签以及更改标题、网址的书签会自动生成用途索引。删除书签时自动清理关联。历史书签按下方勾选范围手动建库；明确排除的目录也会跳过自动建库。

LLM 建库进度

建库文件夹

勾选目录及其子目录参与建库。再次开始时会复用已有摘要，包括仅根据标题和网址生成的摘要。尚无摘要的可处理页面会继续建库。

模型网关

数据与隐私

书签索引、个人备注和 API 密钥保存在当前 Chrome 配置中。普通搜索在本机完成。调用模型时，密钥仅作为身份凭证发给你配置的网关。AI对话搜索会发送查询文字。建库会发送书签标题、处理后的网址及可用的网页摘录。网关如何转发和保存数据取决于服务提供方。远程网关建议使用 HTTPS。
